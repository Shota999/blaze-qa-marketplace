# კონტენტი — სათაური, წინაპირობა, ნაბიჯები

## სათაური (title)

**შაბლონი:** `[მოქმედება] - [სცენარი]`

⚠️ ქეისის სათაურში სუიტის სახელი **არ მეორდება** — ის უკვე suite დონეზეა.

**მაგ.** (სუიტი: `კოლეგიური ორგანოების რეესტრი`):
- ✅ `ძებნა - კოდით`
- ✅ `ფილტრი - სასწავლო წლით`
- ❌ `კოლეგიური ორგანოების რეესტრი - ძებნა - კოდით`

**წესები:**
- სიტყვები სრულად იწერება — შემოკლება დაუშვებელია (`"დაწ."`, `"დრ. განხ."` → ❌)
- em dash (`—`) დაუშვებელია **ყველა ველში** — title, description, preconditions, action, expected_result — მხოლოდ ` - ` (დეფისი + ინტერვალი)
- ინგლისური ტერმინები სათაურში არ გამოიყენება

---

## წინაპირობა (preconditions)

**ყოველთვის ერთი ბლოკი, `\n`-ის გარეშე.**

**ბაზური შაბლონი:**
```
მომხმარებელი ავტორიზირებულია Eschool მოდულში და გადასულია [შესაბამის გვერდზე / ჩანართზე].
```

ქეის-სპეციფიკური მდგომარეობა ემატება კომა ან წერტილით ბაზური ტექსტის შემდეგ:
- `..., გახსნილია კონკრეტული მოსწავლის დეტალური გვერდი და გადასულია [ჩანართი] ჩანართზე. [დამატებითი პირობა.]`

❌ არასოდეს: `base + "\n" + extra`
❌ ავტორიზაციის ნაბიჯი `action`-ში არ ჩაიწერება — ის precondition-შია
